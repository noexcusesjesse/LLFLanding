TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: Email not received
→ Check SENDGRID_API_KEY is correct (no spaces)
→ Verify you completed "Verify a Single Sender" step
→ Wait 2 min and try again
→ Check spam folder

Problem: "Invalid API Key" in Railway logs
→ Copy API key again from SendGrid Settings > API Keys
→ Must be exact (SG.abc123... with no extra spaces)

Problem: Admin dashboard won't log in
→ Verify ADMIN_TOKEN is typed correctly (case-sensitive)
→ Try in incognito window (clears browser storage)

Problem: Form doesn't submit
→ Check Railway deployment completed (wait 30 sec after saving variables)
→ Refresh page (Ctrl+Shift+R or Cmd+Shift+R)
→ Check browser console (F12) for errors

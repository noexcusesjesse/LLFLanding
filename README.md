**Load the Standard. Live the Life.**

A clean, responsive, GitHub Pages-ready landing page for **LoadLine Fitness** and the **LoadLine 365** system.

- **Journey:** Boot Camp (14-day onboarding) → LoadLine 30 / 60 / 90 / 180 / 365 → NOMAD status
- **First live stage:** LoadLine 30, starting September 1, 2026
- **Instagram:** [@LoadLineFitness](https://www.instagram.com/LoadLineFitness/)

## Run locally

No build tools are required.

1. Download or clone the repository.
2. Open `index.html` in a browser.

For a local server, from the repository folder run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy with GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`.
4. Save. GitHub will provide the published site URL.

## Customize

- Main page content: `index.html`
- Colors, layout, typography and responsive behavior: `styles.css`
- Brand images: `assets/`
- Social links are currently set to:
  - `https://www.instagram.com/LoadLineFitness/`
  - `https://x.com/LoadLineFitness`

The site uses no external JavaScript libraries or CSS frameworks, so it is lightweight and easy to maintain.
